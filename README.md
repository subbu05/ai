# ai

- [`stock-trading-agent/`](stock-trading-agent/): a skill-based automated trading agent for stocks, ETFs and options, driven by Claude. Paper trading by default.
- [`trading-dashboard/`](trading-dashboard/): a fast local React + Node trading dashboard with watchlist widgets, buy/sell (market/limit/stop), positions and P&L, and pluggable brokers. Paper trading by default; files stored locally.
